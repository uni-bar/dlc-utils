# 🚀 HOW TO RUN - DOUBLE-CLICK TO LAUNCH

## Target File:

📍 **Location:** `/Users/bareketdamari/Dev/PreyTouch/sandbox/videos/`

🎯 **File to double-click:** `run_app.command`

## Usage:

### Option 1: Double-Click (Easiest)

1. Open Finder
2. Navigate to: `~/Dev/PreyTouch/sandbox/videos/`
3. Find: `run_app.command`
4. **Double-click** 🖱️
5. App launches 🎉

### First Time Setup:

If macOS says "Cannot open because it's from an unidentified developer":

1. **Right-click** (or Control+click) on `run_app.command`
2. Choose **"Open"**
3. Click **"Open"** in the dialog
4. After this, double-clicking will work normally!

### Option 2: Create Desktop Shortcut

To create a desktop shortcut:

1. Open Finder
2. Navigate to: `~/Dev/PreyTouch/sandbox/videos/`
3. Find `run_app.command`
4. Hold **⌘ Command + Option**
5. **Drag** the file to the Desktop
6. This creates an alias - double-click anytime

### Option 3: Add to Dock

1. Open Finder
2. Navigate to: `~/Dev/PreyTouch/sandbox/videos/`
3. **Drag** `run_app.command` to the Dock
4. Click anytime from the Dock

## What It Does:

When double-clicking `run_app.command`:
- ✅ Automatically finds Python (tries PTL conda env first)
- ✅ Opens the DLC Video Overlay app
- ✅ No terminal commands needed

## Troubleshooting:

**"Permission denied"**
→ Open Terminal and run:
```bash
chmod +x ~/Dev/PreyTouch/sandbox/videos/run_app.command
```

**"Python not found"**
→ The app will show a dialog. Ensure Python or Anaconda is installed.

**Nothing happens**
→ Try right-click → Open instead of double-clicking.
